# Setup project on BeagleBone Black

This directory contains directories needed to setup project on BeagleBone Black.

## Contents

```
Debian/

├── bbb-debian   ← directory to load Debian and strip it

├── c7segdisplay ← directory to play video and clock on display from BeagleBone Black

└── README.md    ← this file
```

## Usage

### 1. Follow instruction to load and strip Debian on BeagleBone Black

Go to bbb-debain directory and follow instructions from README.md file in this directory.

### 2. Follow instruction to play video and clock on display from BeagleBone Black

Go to c7segdisplay directory and follow instructions from README.md file in this directory.
